# LasecSimul Help Center

Portal de ajuda gerado a partir do catálogo e das definições reais do LasecSimul. O conteúdo em `docs/` é compilado pelo gerador; edite os comentários estruturados nas fontes ou os artigos em `docs/guide/`.

Gere o portal com `npm run docs:build`. O resultado estático fica em `site/` e pode ser publicado no GitHub Pages pelo workflow do repositório.
